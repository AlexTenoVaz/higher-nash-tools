# Higher Nash Tools

Computational tools for the study of higher Nash modifications and
singularities.

The project provides Python implementations for:

- Higher-order Jacobian matrices.
- Parameterized curves and descent through blow-ups.
- Leading exponents and weighted orders.
- Weighted-order matrices.
- Minimum-cost matchings.
- Complete enumeration of optimal column sets.
- Exact maximal minors.
- Grassmannian separation tests.
